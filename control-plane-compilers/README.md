# One2lv Control Plane Compilers v1.0

**Graph-Compiled Agency Runtime** - The irreversible shift from framework to compiler.

## 🎯 What This Is

You are no longer running modules. You are compiling agency graphs into executable causal manifolds with invariant enforcement and feedback binding.

## 🧠 The Two Compilers

### 1. Distributed Control Plane Compiler
Multi-agent compilation mesh where each agent contributes graph fragments that are fused through consensus-based resolution.

**Features:**
- ✅ Multi-agent graph fragments with deterministic signatures
- ✅ Consensus engine for merging agent graphs
- ✅ Distributed runtime execution engine
- ✅ Thread-safe operations with proper locking
- ✅ Complete example with two agent fragments

### 2. Self-Modifying Compiler
Recursive IBK evolution layer where the compiler itself is subject to invariant constraints and can evolve while preserving its identity.

**Features:**
- ✅ Meta-invariant system governing compiler modifications
- ✅ Compiler operations with validation against invariants
- ✅ Self-modification points for evolutionary growth
- ✅ State persistence with save/load functionality
- ✅ Core kernel protection preventing removal of essential components

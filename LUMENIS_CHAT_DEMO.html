🔧 Setup Instructions

⚠️ API Keys Required

The Lumenis Reactor requires API keys to function:

  • NVIDIA API Key - For Nemotron models (Forge & Oracle seats)
  • Anthropic API Key - For Claude models (main reactor)
  • Astra DB Credentials - For persistent memory (optional)

Step 1: Clone the Repository

git clone https://github.com/one2lv-com/One2lvos.git
cd One2lvos

Step 2: Configure Environment

# Copy the master .env template
cp .env.master .env

# Edit .env and add your API keys
nano .env

# Required keys:
ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
NVIDIA_API_KEY=nvapi-your-key-here
ASTRA_DB_API_ENDPOINT=your-endpoint-here
ASTRA_DB_APPLICATION_TOKEN=your-token-here

Step 3: Install Dependencies

pip install -r requirements.txt

# Or install manually:
pip install fastapi uvicorn anthropic openai httpx aiofiles astrapy

Step 4: Start the Reactor

# Using the startup script:
./start-lumenis-reactor.sh

# Or manually:
python3 lumenis-main.py

# Or with uvicorn (with auto-reload):
uvicorn lumenis-main:app --host 0.0.0.0 --port 3002 --reload

Step 5: Access the Chat UI

# Open in your browser:
http://localhost:3002

# WebSocket endpoint:
ws://localhost:3002/ws

# API status:
http://localhost:3002/api/status

🏗️ Architecture

Frontend:

  • Pure HTML5/CSS3/JavaScript (no frameworks)
  • WebSocket API for real-time communication
  • Canvas API for animated background
  • CSS Grid for responsive layout
  • ~60KB total (uncompressed, self-contained)

Backend:

  • FastAPI server (lumenis-main.py)
  • WebSocket endpoint at /ws
  • ITT Council orchestration
  • Dual LLM support (Claude + NVIDIA Nemotron)
  • Astra DB vector memory

Council Flow:

  1. User sends message → WebSocket
  2. Sentinel checks security → risk assessment
  3. Navigator classifies intent → routing plan
  4. Witness retrieves memory → context injection
  5. Specialist seats (Forge/Oracle/Hermes/Gambit) → execute tasks
  6. Weaver synthesizes → final response
  7. Stream to client → token-by-token display

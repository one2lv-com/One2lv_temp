# Operator Quickstart

You do not need to know the whole system.

## Start here

1. Read the boot console.
2. If it says recovery mode, stay calm.
3. Read the quickstart and recovery docs.
4. Login if you have admin credentials.
5. Open `notes.txt`.
6. Create a snapshot before making edits.
7. Use terminal commands, quick actions, or CLI modules.

## First safe actions

- `policy`
- `task list`
- `task run boot.status`
- `task run docs.list`
- `task run workspace.list`
- `task run module.run recovery`

## What this system is

This is a recovery-first control center built on a CLI module runtime.
The web interface is a loader and control surface, not the only way to use the system.

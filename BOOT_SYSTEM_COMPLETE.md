## 🎯 **User Workflows**

### Workflow 1: Normal Boot
1. Access http://localhost:9000/
2. See boot selector (30s countdown)
3. Click "BIOS Boot Menu" or wait for auto-boot
4. Use BIOS to access any service
5. Click service to view embedded
6. Close and switch to another service

### Workflow 2: Emergency Recovery
1. Access http://localhost:9000/RECOVERY.html
2. Run diagnostics to identify issues
3. Click service recovery button
4. View console output
5. Test service in embedded viewer
6. Return to BIOS or continue recovery

### Workflow 3: Direct Access
1. Access http://localhost:9000/BIOS_BOOT.html
2. Click any "External Link" button
3. Service opens in new tab
4. BIOS remains open for quick switching
